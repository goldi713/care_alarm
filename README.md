# care_alarm# ❤️ CareAlarm – Smart Care & Reminder

CareAlarm is a simple and user-friendly web application designed to help users manage **medicine reminders, daily activity reminders, family contacts, and emergency alerts**.

## 🌟 Features

* ⏰ **Medicine Reminders**

  * Add multiple medicines
  * Set specific reminder times
  * Select specific days or daily reminders
  * Edit and delete reminders

* 💧 **Water Reminder**

  * Set reminders to drink water
  * Stop or snooze reminders

* 🚶 **Walk Reminder**

  * Set walking/activity reminders
  * Stop or snooze reminders

* 😴 **Sleep Reminder**

  * Set sleep/rest reminders
  * Stop or snooze reminders

* 👨‍👩‍👧 **Family Contacts**

  * Add emergency contacts
  * Save contact name and phone number
  * Select a preferred emergency contact
  * Edit/delete contacts

* 🚨 **Emergency Alert**

  * Call the selected emergency contact
  * Open WhatsApp with the selected contact
  * Send an emergency alert message

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage
* WhatsApp URL integration

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Run it using a browser or **Live Server**.
5. Allow browser permissions if required.

## 🚨 Emergency Alert Usage

First add a family/emergency contact and select it as the preferred contact.

When **Send Alert** is pressed:

* The selected contact is used for the emergency call.
* WhatsApp opens with the selected contact.
* The emergency message can be sent through WhatsApp.

## 💾 Data Storage

CareAlarm uses the browser's **Local Storage** to save reminders and contacts locally on the device.

## 🎯 Project Objective

The main objective of CareAlarm is to provide an easy-to-use reminder and emergency assistance system, especially for users who need help remembering medicines, daily activities, and important contacts.
